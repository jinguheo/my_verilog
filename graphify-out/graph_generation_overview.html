How It Is Generated

1. AST extraction
Graphify extracts modules, functions, imports, call links, contains links, and other code structure from the repository. This code-only update path does not require an LLM call.
2. Graph merge
The extracted nodes and edges are merged into a NetworkX node-link JSON file at graphify-out/graph.json.
3. Community assignment
Each graph node carries a community attribute. The overview views use those community ids to group the large graph into smaller visual layers.
4. HTML export
Graphify's export.to_html() writes vis-network based HTML. The default Graphify exporter limits very large graphs, so this workspace generated the full HTML by raising that local visualization limit for this run.
5. Compact views
The compact views collapse communities into larger nodes so the architecture can be inspected before opening the full 55 MB graph page.
Practical tip: open the SVG or top community HTML first. Open the full graph only when you need exact node-level search and inspection.

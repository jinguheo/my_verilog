# Summary: Ibex Documentation Index

This document is the top-level entry point for the **Ibex** documentation. It introduces Ibex as an **open-source, production-quality, highly parameterizable 32-bit RISC-V CPU core** written in SystemVerilog, intended primarily for **embedded control applications**. The document emphasizes that Ibex is extensively verified and has already been through multiple tape-outs, signaling a mature and hardware-proven design.

## Main purpose

The page acts as a **navigation hub** for the full documentation set. It explains that the documentation is divided into four parts:

1. **Overview documentation** — high-level properties, standards compliance, and typical use cases.
2. **User Guide** — practical guidance for integrating Ibex into hardware designs and for writing software that runs on Ibex.
3. **Reference Guide** — deeper technical background, including design details, verification strategy, and testbench structure.
4. **Developer Guide** — guidance for contributors modifying Ibex itself and participating in the open development process.

## Key ideas

- **Ibex is a RISC-V processor core** focused on embedded systems.
- It is **heavily parametrizable**, making it adaptable to different integration needs.
- The documentation is organized by audience and intent:
  - high-level understanding,
  - practical usage,
  - technical reference,
  - core development.
- The project is **open source**, and the documentation encourages users to become contributors.

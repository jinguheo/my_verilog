# Licensing

This document states that **Ibex** is released under the **Apache License 2.0**.

## Key points

- Ibex may be **used, modified, and distributed** for any purpose, including commercial use.
- There are standard Apache 2.0 requirements, especially around **preserving copyright notices** and **including the original license**.
- The full and legally binding terms are in the repository’s `LICENSE` file.
- Although not required by the license, the project welcomes **feedback and contributions** to improve Ibex.
- Users are encouraged to report bugs, ask questions, or suggest improvements via a GitHub **issue**, and to contribute code through a **pull request**.
- **Commercial support** is available from lowRISC.

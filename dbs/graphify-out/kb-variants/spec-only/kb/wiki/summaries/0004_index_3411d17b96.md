# Summary: Introduction to Ibex

This document introduces **Ibex**, an open-source **32-bit RISC-V CPU core** written in **SystemVerilog**. It positions Ibex as a **production-quality**, **heavily parametrizable** processor aimed at **embedded control applications**.

## Key points

- **Open-source RISC-V core**: Ibex implements a 32-bit RISC-V CPU design.
- **SystemVerilog implementation**: The core is written in SystemVerilog.
- **Parametrizable architecture**: It is designed to be highly configurable for different use cases.
- **Embedded focus**: The target application area is embedded control systems.
- **Mature verification status**: Ibex is described as extensively verified and has undergone multiple tape-outs.

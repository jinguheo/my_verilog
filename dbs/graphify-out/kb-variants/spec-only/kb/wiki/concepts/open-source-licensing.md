# Open Source Licensing

Open source licensing defines the legal terms under which software can be used, modified, and redistributed. In the case of [[summaries/0005_licensing_d3fe8b66d2]], **Ibex** is released under the **Apache License 2.0**, which is a permissive license designed to allow broad use, including commercial applications.

## What this means

Ibex’s license grants users the freedom to:

- **Use** the software for any purpose
- **Modify** the source code to fit their needs
- **Distribute** original or modified versions
- **Use commercially** without paying royalties

These freedoms make Apache 2.0 a common choice for projects that want to encourage adoption and collaboration while keeping basic legal protections in place.

## Core obligations

Although permissive, Apache 2.0 still requires attention to a few important conditions:

- Keep the **copyright notices** intact
- Include the **license text** with redistributions
- Follow the terms in the repository’s `LICENSE` file, which is the authoritative legal reference

This balance of flexibility and attribution is a defining feature of the license.

## Community and contribution culture

The document also emphasizes that licensing is not only about legal permission; it shapes how a project engages with its community. Even though contributions are not required by the license, the project encourages:

- filing [[concepts/contributor_workflow|issues]] for bugs, questions, or improvements
- submitting [[concepts/contributor_workflow|pull requests]] with code changes
- sharing feedback to improve the project for everyone

## Commercial support

A permissive open source license does not prevent commercial services around the project. The document notes that **commercial support** is available from lowRISC, showing how open source licensing can coexist with paid support offerings.
